REVIEWER PORTRAITS
==================

Drop reviewer photos here, then set the matching `photo` field in
src/data/content.js, e.g.:

  photo: '/images/testimonials/shehjad-khan.jpg'

Square images, 300x300 or larger. Until a file is supplied the card
shows an initials monogram instead.

IMPORTANT: get each reviewer permission before using their photo.
Do not copy portraits from LinkedIn profiles.
